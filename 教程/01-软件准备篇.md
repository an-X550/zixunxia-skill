## 一、认识你需要安装的东西

### 1.1 咨询侠是什么

咨询侠是一个运行在 **Claude Code** 里面的"技能包"（Skill）。

打个比方：Claude Code 就像你手机上的操作系统（iOS 或安卓），咨询侠就像你装的一个 App。你要先有手机系统，才能装 App；同理，你要先装好 Claude Code，才能使用咨询侠。

咨询侠的作用：在你进行高考志愿咨询时，帮你做三件事——
- **咨询前**：分析考生信息，生成题目包和专业推荐文档
- **咨询中**：提供标准化话术，引导你完成五维度讲解
- **咨询后**：基于聊天记录生成 AI 复盘报告

简单说：**你是咨询官，咨询侠是你的 AI 副驾驶。** 你负责跟考生沟通、做判断、把控节奏；咨询侠负责帮你准备材料、提供话术、生成文档。

### 1.2 你需要安装哪些东西

总共需要安装 **4 样东西**（核心）：

| 序号 | 名称 | 一句话用途 | 必须？ | 安装方式 |
|------|------|-----------|--------|---------|
| 1 | Node.js | Claude Code 的运行基础 | ✅ 必须 | 🖐️ 手动 |
| 2 | Agent 平台 | 咨询侠的运行平台 | ✅ 必须 | 🖐️ 手动（Claude Code / WorkBuddy / Trae 任选） |
| 3 | Python 3 | 导出 Word 文档（docx） | ✅ 必须 | 🖐️ 手动（WorkBuddy 用户可跳过） |
| 3 | Python 3 | 导出 Word 文档（docx） | ✅ 必须 | 🖐️ 手动 |
| 4 | mcporter | 连接腾讯文档和腾讯问卷 | ✅ 必须 | 🤖 AI 可代劳 |

另外还有 **可选配置**：

| 名称 | 用途 | 安装方式 |
|------|------|---------|
| VSCode | 在编辑器里使用 Claude Code，界面更友好 | 🖐️ 手动 |
| 第三方 API Key | 使用 DeepSeek 等国产模型，降低成本 | 🖐️ 获取 Key / 🤖 配置 |
| 腾讯文档 | AI 生成的专业推荐一键变成在线文档链接 | 🖐️ 获取 Token / 🤖 配置 |
| 腾讯问卷 | AI 生成的题目包一键变成在线问卷 | 🖐️ 获取 Token / 🤖 配置 |

> 💡 **提示**：第一次使用可以先跳过可选配置。等熟悉了基本流程再回头配。

### 1.3 检查你的电脑

在开始之前，确认以下几点：

- **操作系统**：Windows 10 或更高版本（本项目团队使用 Windows）
- **网络**：能正常访问互联网（需要下载安装包）
- **权限**：安装过程中部分步骤可能需要管理员权限（你的个人电脑默认就有）
- **磁盘空间**：至少 500MB 可用空间

> **检查点**：你用的是 Windows 10 或 Windows 11 吗？（设置 → 系统 → 关于 中可以查看）

## 二、安装 Claude Code

> ⚠️ **本章全部需要你手动操作**——Node.js 和 Claude Code 的安装是 AI 介入前的准备工作。安装完成后 AI 才能帮你。

### 2.1 Claude Code 是什么

Claude Code 是一个运行在**终端**（命令行界面）里的 AI 助手。你不需要会编程——你跟它的对话就是操作界面。你输入文字指令，它回复文字内容。就这么简单。

> 📌 **术语解释**：本文中"终端"指的是 Windows 自带的 **PowerShell**。打开方式：按键盘上的 `Win + R`，输入 `powershell`，回车。你会看到一个黑底白字的窗口——这就是终端。

### 2.2 安装 Node.js

Node.js 是 Claude Code 的运行基础，必须先装。

> 🖐️ **以下全部需要你手动操作**

**第一步：下载**

打开浏览器，访问：https://nodejs.org

页面中间有两个大按钮。点击左边的 **LTS** 版本（长期稳定版）。右边那个是尝鲜版，不要选。

> 💡 LTS 版本号通常是偶数，比如 18.x、20.x。只要版本号 ≥ 18 就行。

**第二步：安装**

1. 双击下载的安装包（`node-vXX.XX.X-x64.msi`）
2. 看到 "Welcome" 界面 → 点 **Next**
3. 看到许可协议 → 勾选 "I accept"，点 **Next**
4. 看到安装路径 → 不用改，直接点 **Next**
5. 看到功能选择 → 不用改，直接点 **Next**
6. 看到 "Ready to install" → 点 **Install**
7. 如果弹出"是否允许此应用修改设备" → 点 **是**
8. 看到 "Completed" → 点 **Finish**

**第三步：验证** 🖐️

打开终端（`Win + R` → 输入 `powershell` → 回车），输入：

```powershell
node --version
```

如果安装成功，你会看到类似这样的输出：

```
v20.11.0
```

> ⚠️ **如果提示"'node' 不是内部或外部命令"**：
> 说明安装过程中出现了问题。重启电脑后再试一次 `node --version`。如果还是不行，重新运行安装包，在安装时确认所有选项保持默认。

> **检查点**：你的终端能显示 node 版本号（形如 `vXX.XX.X`）。

### 2.3 安装 Claude Code

> 🖐️ **手动操作**

Node.js 装好后，在同一个终端窗口中输入：

```powershell
npm install -g @anthropic-ai/claude-code
```

> 📌 **术语解释**：`npm` 是 Node.js 自带的包管理工具（可以理解为"应用商店"）。`install -g` 的意思是"全局安装"，装完后在任何目录都能使用。

这个命令会下载并安装 Claude Code，可能需要 1-3 分钟，取决于你的网络速度。你会看到一堆滚动文字，最后出现类似这样的提示就说明成功了：

```
added xxx packages in xx s
```

验证 🖐️：

```powershell
claude --version
```

如果显示版本号（如 `v1.0.0` 或类似格式），说明安装成功。

> **检查点**：你的终端能显示 claude 版本号。

### 2.4 登录 Claude Code

> 🖐️ **手动操作**（需要浏览器登录）

在终端中输入：

```powershell
claude
```

首次启动时，Claude Code 会引导你登录：

1. 终端会显示一个验证链接（以 `https://` 开头）
2. 用鼠标选中这个链接，复制（`Ctrl + C`）
3. 粘贴到浏览器地址栏，回车打开
4. 在浏览器页面中登录你的 Claude 账号
5. 登录成功后，浏览器页面会显示"验证成功"
6. 回到终端，Claude Code 会自动进入对话界面

如果还没有 Claude 账号，在浏览器页面中选择注册。目前 Claude Code 提供免费额度，日常使用足够。

登录成功后，终端会显示 Claude Code 的欢迎界面。此时输入：

```
/exit
```

退出 Claude Code，回到终端。

> ⚠️ **注意**：后续每次启动都要在终端输入 `claude` 并回车。Claude Code 本身不创建桌面快捷方式——你需要记住这个启动方式。

> **检查点**：你能正常启动并登录 Claude Code。

> ✅ **🎉 从这里开始，Claude Code 已经可以对话了！后续所有 🤖 标记的命令，你都可以直接复制给 AI，让 AI 帮你执行——不需要自己开终端。**

### 2.5 在 VSCode 中使用 Claude Code（推荐）

如果你觉得每次都要打开终端太麻烦，可以直接在 **VSCode**（Visual Studio Code）里使用 Claude Code。VSCode 是微软出的一款免费代码编辑器——不用担心，你不需要会写代码，我们只是用它来运行 Claude Code。

> 🖐️ **以下全部需要你手动操作**（GUI 安装）

**第一步：下载 VSCode**

打开浏览器，访问：https://code.visualstudio.com

点击大按钮下载安装包，双击安装。安装过程一路"下一步"即可，全部保持默认选项。

**第二步：安装 Claude Code 扩展**

1. 打开 VSCode
2. 点击左侧竖条工具栏上的**扩展图标**（四个方块组成的正方形，或按 `Ctrl+Shift+X`）
3. 在搜索框中输入 `Claude Code`
4. 找到 Anthropic 官方发布的 **Claude Code** 扩展，点击 **安装**
5. 安装完成后，左侧工具栏会出现 Claude Code 的图标

**第三步：打开 Claude Code**

点击左侧的 Claude Code 图标，VSCode 会在底部或侧边打开一个对话面板。这个面板和终端里的 Claude Code 是一样的——你输入文字，AI 回复文字。

> 💡 **好处**：VSCode 版的 Claude Code 不需要每次打开终端，界面也更友好。后续所有操作（对话、查看文件）都在一个窗口里完成。

> **检查点**：VSCode 里能正常打开 Claude Code 对话面板。

> 📺 **视频演示**：B站 UP主「沉默的羔丸voov」的实操视频——[在VSCode中使用Claude Code agent并配置DeepSeek v4 model](https://www.bilibili.com/video/BV1ia9UBPESQ/)（23万播放），手把手演示了 VSCode + Claude Code + DeepSeek 的完整配置过程，强烈推荐对照观看。

### 2.6 配置第三方 API Key（可选，降低成本）

Claude Code 默认使用 Anthropic 官方的 API，按用量收费。如果你想**使用其他 AI 服务商的 API**（比如 DeepSeek，价格更低），可以通过环境变量配置。

> 📌 **为什么要配第三方 API**：Anthropic 官方 API 按 token 计费，高频使用成本较高。DeepSeek 等国产模型 API 价格更低，且中文能力不逊色。咨询侠的日常使用场景（生成题目包、话术、推荐文档）完全可以用国产模型替代。

#### 第一步：获取第三方 API Key 🖐️

以 DeepSeek 为例：
1. 访问 https://platform.deepseek.com
2. 注册账号并登录
3. 进入「API Keys」页面，点击「创建 API Key」
4. 复制生成的 Key（以 `sk-` 开头）

> 其他兼容 OpenAI 接口的服务商（如 Moonshot、智谱、通义千问等）同理，获取对应 API Key 即可。

#### 第二步：配置环境变量 🤖

> 🤖 **以下命令可直接复制给 AI，让 AI 帮你配置**

```powershell
# 设置 API 地址（以 DeepSeek 为例）
[System.Environment]::SetEnvironmentVariable('ANTHROPIC_BASE_URL', 'https://api.deepseek.com/v1', 'User')

# 设置 API Key（告诉 AI 你的 Key，AI 帮你填入并执行）
[System.Environment]::SetEnvironmentVariable('ANTHROPIC_API_KEY', 'sk-你的DeepSeek-API-Key', 'User')
```

> 💡 **其他服务商**：只需要改 `ANTHROPIC_BASE_URL` 为对应服务商的 API 地址即可。例如：
> - 智谱：`https://open.bigmodel.cn/api/paas/v4`
> - Moonshot：`https://api.moonshot.cn/v1`

#### 第三步：验证 🤖

配置完成后，**关闭当前终端，重新打开**（环境变量需要新终端才能生效），启动 Claude Code：

```powershell
claude
```

如果正常启动并进入对话界面，说明配置成功。AI 回复时使用的就是你的第三方 API 了。

> ⚠️ **注意**：
> - 第三方 API 的功能可能不完全等同于 Anthropic 官方——例如某些高级工具调用可能有差异。日常使用足够。
> - 如果后续想切回 Anthropic 官方 API，删除或修改上述环境变量即可。
> - VSCode 中的 Claude Code 同样使用这些环境变量，无需额外配置。

> **检查点**：使用第三方 API Key 后 Claude Code 能正常启动和对话。

> 💡 本篇后续章节以 Claude Code 为默认平台讲解。如果你选了其他工具，只需把 Skill 目录路径换成上表对应的路径，其余操作完全一样。

### 3.1 找到咨询侠 Skill 文件夹

> 🖐️ **手动操作**

咨询侠 Skill 是以文件夹形式交付的。找到你收到的 `咨询侠/` 文件夹，确认里面有一个叫 `SKILL.md` 的文件——这是 Skill 的核心定义文件，有这个文件才说明文件夹是完整的。

> 📌 文件夹可能在一个 U 盘里，也可能是一个压缩包（.zip）。如果是压缩包，先右键 → "全部解压缩"到一个你方便找到的位置（比如桌面）。

### 3.2 复制到 Claude Code 的 Skills 目录

> 🖐️ **手动操作**（文件管理器操作）

Claude Code 的所有 Skill 都放在一个固定位置：

```
C:\Users\{你的Windows用户名}\.claude\skills\
```

> 💡 `{你的Windows用户名}` 需要替换成你电脑的实际用户名。如果你不确定，打开终端输入 `echo $env:USERNAME`（🤖 也可以让 AI 帮你查），显示的就是你的用户名。

**操作步骤**：

1. 打开文件资源管理器（`Win + E`）
2. 在地址栏输入 `C:\Users\{你的用户名}\.claude\` 并回车
3. 如果看到 `skills` 文件夹，打开它；如果没看到，手动新建一个名为 `skills` 的文件夹
4. 打开另一个文件资源管理器窗口，找到咨询侠 Skill 文件夹（来源）
5. 将整个 `咨询侠/` 文件夹**复制**（不是移动）到 `skills/` 目录下

最终路径应该是：

```
C:\Users\{你的用户名}\.claude\skills\咨询侠\SKILL.md
```

> ⚠️ **非常重要**：文件夹名称必须是 `咨询侠`，不能改名。Claude Code 通过文件夹名来识别 Skill。如果改成了"咨询侠v2""咨询侠(1)"之类的名字，Skill 将无法加载。

> **检查点**：确认 `SKILL.md` 文件存在于 `C:\Users\{你的用户名}\.claude\skills\咨询侠\` 目录下。

### 3.3 验证 Skill 已加载

> 🤖 **以下可以交给 AI**（Claude Code 已经在运行了）

重新启动 Claude Code（终端输入 `claude`，或打开 VSCode 中的 Claude Code 面板）。

进入对话界面后，输入：

```
你好，请确认咨询侠 Skill 是否已加载
```

如果 AI 的回复中包含"咨询侠"相关内容，或者开始引导你配置环境（询问 Python、Node.js 是否已安装），说明 Skill 加载成功。

如果 AI 说不知道咨询侠是什么，说明 Skill 没有正确加载。请回到 3.2 检查文件夹路径是否正确，特别注意：
- 文件夹名是否就是 `咨询侠`（没有多余字符）
- 路径是否在 `.claude\skills\` 下面

> **检查点**：AI 能识别"咨询侠"这个名称并做出回应。

## 四、安装 Python 环境

### 4.1 Python 用来做什么

咨询侠有一个功能是**把 AI 生成的分析报告导出为 Word 文档**（`.docx` 格式），这样你就可以直接微信发给考生。这个功能需要 Python 来运行。

一句话：没有 Python，你就没法用 `导出docx` 这个指令。

> 📌 如果你的电脑之前已经装过 Python，跳过 4.2，直接让 AI 帮你做 4.3。

### 4.2 下载并安装 Python

> 🖐️ **全部手动操作**（GUI 安装）

**第一步：下载**

打开浏览器，访问：https://python.org

鼠标移到 "Downloads" 菜单，页面会自动识别你是 Windows 系统，显示一个大的下载按钮。点击下载最新版（如 Python 3.12.x）。

**第二步：安装**

1. 双击下载的安装包（`python-3.XX.X-amd64.exe`）
2. ⚠️ **最关键的一步**：在安装界面的**底部**，勾选 **"Add Python to PATH"**（把 Python 添加到系统路径）。这个复选框很小，容易被忽略，但它决定了你后续能不能在终端里直接使用 Python。
3. 勾选之后，点击上方的大按钮 **"Install Now"**
4. 等待安装完成
5. 看到 "Setup was successful" → 点 **Close**

**第三步：验证** 🤖（可以让 AI 帮你验证）

打开终端，输入：

```powershell
python --version
```

如果看到类似 `Python 3.12.4` 的输出，说明安装成功。

> ⚠️ **如果提示找不到 python**：试试输入 `python3 --version` 或 `py --version`。如果 `py --version` 能显示版本号但 `python --version` 不行，说明安装时没有勾选 "Add Python to PATH"。建议重装 Python，这次一定勾选那个复选框。

> **检查点**：终端能显示 Python 版本号。

### 4.3 安装 python-docx 库

> 🤖 **以下全部可以交给 AI 执行**

Python 装好后，还需要安装一个叫 `python-docx` 的工具包，它专门用来生成 Word 文档。

**你可以直接对 AI 说**：「帮我在终端里执行 `pip install python-docx`」

或者自己手动敲：

```powershell
pip install python-docx
```

等待安装完成，看到 "Successfully installed python-docx-X.X.X" 就说明成功了。

验证（🤖 也可让 AI 代劳）：

```powershell
pip show python-docx
```

如果显示了包名、版本号等信息，说明安装没问题。

> **检查点**：`pip show python-docx` 能正常显示包信息。

## 六、配置腾讯文档（可选）

### 6.1 这是什么

配置后，AI 生成的专业推荐文档可以**一键变成腾讯文档链接**，考生在手机上点开就能看。不需要你下载 Word 文件再微信发送。

如果不配置，你仍然可以用 `导出docx` 指令生成 Word 文件手动发给考生——完全够用。

### 6.2 获取 Token

> 🖐️ **手动操作**（需要浏览器登录）

> 📌 **术语解释**：Token（令牌）是一串长字符，相当于你的"数字钥匙"。有了它，咨询侠才能代表你操作腾讯文档。

1. 打开浏览器，访问：https://docs.qq.com/scenario/open-claw.html
2. 登录你的腾讯文档账号（QQ 或微信登录都可以）
3. 页面中会有一个"创建 Token"的按钮，点击
4. 复制生成的 Token 字符串（很长一串，以 `docs-` 开头）

> ⚠️ **这个 Token 不要分享给任何人。** 它相当于你的腾讯文档密码。

### 6.3 配置 mcporter

> 🤖 **以下全部可以交给 AI 执行**——把 Token 发给 AI，AI 帮你配置

**对 AI 说**：「帮我在终端执行以下命令，Token 是 `docs-你的Token字符串`」

```powershell
mcporter config add tencent-docs "https://docs.qq.com/openapi/mcp" --header "Authorization=docs-你的Token" --transport http --scope home
```

> 💡 如果你自己手动执行，把 `docs-你的Token` 替换为 6.2 中复制的完整字符串即可。

### 6.4 验证 🤖

```powershell
mcporter list tencent-docs
```

如果返回一列工具名称（英文列表），说明配置成功。如果返回错误，检查 Token 是否完整复制，有没有多复制了空格。

> **检查点**：`mcporter list tencent-docs` 返回工具列表而非报错。

> ⚠️ **注意**：Token 有时效性（腾讯文档会定期让它过期）。如果某天发现腾讯文档功能突然不能用了，回到 6.2 重新获取 Token，然后告诉 AI 新的 Token 让它重新配置。

## 七、配置腾讯问卷（可选）

### 7.1 这是什么

配置后，AI 生成的题目包可以**一键导出为腾讯问卷链接**。考生在手机上填答，答案自动回收，AI 直接读取分析。

如果不配置，你需要手动复制题目发给考生，考生答完后再手动把答案录入给 AI——也能工作，但比较麻烦。

### 7.2 获取 Token

> 🖐️ **手动操作**（需要浏览器登录）

1. 打开浏览器，访问：https://wj.qq.com/claw
2. 登录你的腾讯问卷账号
3. 创建 Token
4. 复制 Token（以 `wjpt_` 开头，大约 70 个字符）

### 7.3 配置

> 🤖 **以下全部可以交给 AI 执行**——把 Token 发给 AI，AI 帮你配

**方式一：环境变量（简单，但关掉终端后失效）**

```powershell
$env:TENCENT_SURVEY_TOKEN = "wjpt_你的Token"
```

> ⚠️ 这种方式在你关闭终端窗口后就失效了，下次使用前需要重新执行。

**方式二：mcporter 持久化配置（推荐，一次配置永久有效）**

**对 AI 说**：「帮我在终端配置 tencent-survey，Token 是 `wjpt_你的Token字符串`」

```powershell
mcporter config add tencent-survey "https://wj.qq.com/api/v2/mcp" --header "Authorization=Bearer wjpt_你的Token" --transport http --scope home
```

> 💡 推荐直接用方式二，省得每次都要重新设置。

### 7.4 验证 🤖

```powershell
mcporter list tencent-survey
```

返回工具列表即成功。如果报错，检查 Token 是否完整（注意 `wjpt_` 前缀不能丢）。

> **检查点**：`mcporter list tencent-survey` 返回工具列表而非报错。
