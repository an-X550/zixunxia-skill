# 咨询侠 — 高考志愿咨询 AI 副驾驶

> 作者：谢安 | 基于问问大象「撑伞侠」工作流体系构建 | v2.6.0

AI 作为内容引擎，咨询官（人类咨询侠）做需求翻译和决策过滤。核心原则：**授人以渔，而非授人以鱼**。

---

## 部署（拿到压缩包后 3 步就绪）

### 第 1 步：解压 + 安装

解压到任意目录，双击 `setup.bat`。脚本自动用阿里云镜像安装全部依赖。

> 前提：电脑已有 Python 3。没有的话去 [python.org](https://python.org) 下载安装。

### 第 2 步：设置 API Key

方式一（推荐）——在项目根目录新建 `.env` 文件，写入：

```
DEEPSEEK_API_KEY=你的DeepSeek_API_Key
```

方式二——终端里执行：

```bash
set DEEPSEEK_API_KEY=你的DeepSeek_API_Key
```

> 同一把 Key 用于 Claude Code 对话和批量模式。Key 从 [platform.deepseek.com](https://platform.deepseek.com) 获取。

### 第 3 步：打开 Claude Code

用 Claude Code 打开项目目录，Skill 自动加载。首次使用 AI 会引导你完成环境检查 + 排期表创建。

### 可选：在线服务

| 服务 | 用途 | 配置方式 |
|------|------|---------|
| 腾讯文档 | 专业推荐/复盘报告 → 在线文档 + 分享链接 | docs.qq.com 获取 Token |
| 腾讯问卷 | 题目包 → 在线问卷，考生手机作答 | wj.qq.com 创建 Token（wjpt_ 开头） |

跳过在线服务不影响核心功能，只是不能一键生成在线文档和问卷。需要时在 Claude Code 里说 `导出腾讯问卷` 或 `创建在线推荐`，AI 会引导配置。

## 日常指令速查

### 咨询前 — AI 分析引擎

| 你要做什么 | 指令 |
|-----------|------|
| 激活/创建考生 | `@咨询侠:切换:昵称` |
| 触发咨询前流程 | `开始咨询前准备` 或直接粘贴考生信息 |
| 生成题目包 | `生成题目包` |
| 一键导出在线问卷 | `导出腾讯问卷` |
| 回收答案 | `考生已作答` + 粘贴答案 |
| 生成专业推荐 | `生成专业推荐` |
| 生成城市推荐 | `生成城市推荐` |
| 导出 Word | `导出docx` |
| 在线分享 | `创建在线推荐` |

### 批量模式（多人并行）

| 你要做什么 | 指令 |
|-----------|------|
| 触发批量分析 | `批量分析` 或 `贴学生数据` |
| 粘贴多人数据 | 每行一位：`张三 province=广东 score=580 major_interests=自动化` |
| 查看需跟进考生 | AI 自动输出 `@咨询侠:切换:xxx` 列表 |

也支持 CSV 文件：`python batch/run_batch.py 学生列表.csv`

### 咨询中 — 自动推进（v2.4.0）

输入 `开始咨询` 后，AI 自动按优先级推进流程，你**只需在 3 个审批点确认**。每个 turn 末尾显示进度条：

```
📍 进度：培养计划 ✅ → 学校要求 🔵 → 深造要求 ⬜
```

**手动覆盖指令**（随时可用）：

| 指令 | 效果 |
|------|------|
| `暂停自动推进` | 切回手动模式，停在当前位置 |
| `恢复自动推进` | 继续自主推进 |
| `跳过：城市推荐` | 跳过指定板块 |
| `讲培养计划` / `讲学校要求` 等 | 立即跳到指定维度 |
| `答疑：纠结` / `答疑：焦虑` 等 | 切入对应答疑场景 |
| `结束咨询` | 输出通用总结 + 收尾 |

**人工审批点**（AI 不会自动跨过）：
1. 专业推荐生成后 — 审核推荐结果
2. 五维度全部完成 — 确认是否继续城市/院校
3. 收尾前 — 确认可以结束

### 咨询后 — AI 复盘

| 指令 | 作用 |
|------|------|
| `开始复盘` | 粘贴聊天记录或会议转写 |
| `输出复盘` | 四步复盘：问题→手段→效果→改进 |
| `导出复盘` | 生成 DOCX 文件 |

### 辅助指令

| 指令 | 作用 |
|------|------|
| `当前进度` | 查看考生所有节点完成状态 |
| `检查遗漏` | 对照全流程清单检查 |
| `考生列表` | 列出所有考生 |
| `@咨询侠:切换:昵称` | 切换服务对象 |
| `考生信息：字段 = 值` | 更新档案字段 |
| `检测人机感 + 文本` | 标注 AI 痕迹 + 输出优化版 |
| `父母干预` / `考生未到` / `延时申请` | 特殊场景话术 |

## 自然语言推断

除了精确指令，你也可以用自然语言，AI 自动识别意图：

| 你说了什么 | AI 推断为 | 自动执行 |
|-----------|----------|---------|
| 「帮这个考生分析一下」 | 咨询前-专业推荐 | 检查信息是否足够 |
| 「开始跟考生聊了」 | 咨询中 | 切换模式，开始自动推进 |
| 「帮我看看这次咨询哪里有问题」 | 咨询后-复盘 | 引导粘贴材料 |
| 「接下来讲 XX 维度」 | 指定维度 | 输出该维度话术 |
| 「考生好像很紧张」 | 答疑-焦虑 | 暂停推进，切入安抚话术 |
| 「该结束了」 | 收尾 | 输出总结 + 收尾话术 |
| 「太快了」「慢一点」 | 暂停 | 停在当前位置 |
| 「贴学生数据」然后粘贴多行 | 批量分析 | 解析 → 写入 → 并行分析 |

## 话术个性化

AI 自动根据考生画像调整语气和侧重点——焦虑型多安抚、纠结型多对比表格、低分段强调非学历路径、经济高压型展开薪资数据。也可随时说「换个语气」「太啰嗦了精简」。
