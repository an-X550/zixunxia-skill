# create_survey 工具参考

> 咨询侠精简版：只保留咨询侠使用的调查场景（scene=1）和常用题型。
> 完整 DSL 语法见[官方文档](https://wj.qq.com/docs/survey-dsl/content/)。

## 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `text` | string | **是** | 问卷内容文本，换行使用 `\n` |
| `scene` | number | 否 | 问卷场景，默认 1（调查） |
| `project_id` | number | 否 | 项目 ID |

## 返回值

```json
{"survey_id": 716128, "hash": "859f"}
```

> 投放链接：`https://wj.qq.com/s2/{survey_id}/{hash}`

## text DSL 语法

### 基础结构

```
问卷标题

问卷引导语（可选）

题目标题[题型](描述)
选项/内容
```

- 第一行为问卷标题
- 标题后可跟引导语（可选）
- `=== 分页 ===` 插入分页符
- 题目之间用空行分隔
- **JSON 中所有换行用 `\n`**

### 咨询侠常用题型

| 题型 | 语法 | 用途 |
|------|------|------|
| 单选题 | `标题[单选题]\n选项A\n选项B` | 信息确认、偏好选择 |
| 多选题 | `标题[多选题]\n选项A\n选项B` | 多维度确认 |
| 单行文本题 | `标题[单行文本题]` | 简短文字输入 |
| 多行文本题 | `标题[多行文本题]` | 详细说明 |
| 量表题 | `标题[量表题]\n1~5` | 程度/满意度打分 |
| 多项填空题 | `标题[多项填空题]\n填空1：____` | 多字段填答 |
| 下拉题 | `标题[下拉题]\n选项A\n选项B` | 选项多的单选 |
| 段落说明 | `内容[段落说明]` | 纯文本说明（非题目） |

### 题目设置

| 设置 | 语法 | 说明 |
|------|------|------|
| 必答 | `[必答]` | 该题必须作答 |
| 选答 | `[选答]` | 该题可跳过 |

例子：`您的姓名[单行文本题][必答](请填写真实姓名)`

- `[单选题]` 是默认题型，可省略方括号
- `(描述)` 是可选的题目说明

### 富文本

| 类型 | 语法 |
|------|------|
| 高亮 | `**高亮文本**` |
| 链接 | `[链接文本](https://...)` |

## 咨询侠题目包示例

```
旭日-信息确认题

以下问题用于确认你的关键偏好，请如实作答～

1. 关于"国网稳定"和"机械技术"，你的真实想法是？[单选题]
两个都要，最好能找到兼顾的路
优先国网，稳定第一
优先机械，技术第一
还不确定，想都了解一下

2. 关于工作节奏，你更倾向哪种？[单选题]
长期稳的，起薪低点但不会失业，熬几年就上来
快速变现，起薪高但可能不稳定
两者都可以接受

3. 以下哪种工作方式最符合你的想象？[多选题]
工厂产线技术员/工程师，自己动手调试设备
和团队协作完成项目
独立研究/设计
和客户沟通对接

4. 关于出省读大学，你的想法是？[单选题]
铁定去外地，越远越好
看情况，如果省外学校明显更好就去
优先留在省内
```

## 调用示例

```
mcporter call tencent-survey.create_survey --args '{"text": "满意度调查\n\n1. 满意吗？[单选题]\n满意\n不满意"}'
```

## 注意事项

1. **text 必填**，换行用 `\n`
2. **选项不需要字母前缀**：写 `满意` 而非 `A. 满意`
3. **题目内不允许空行**，会被识别为两道题
4. **量表范围用 `~`**：`1~5`
5. **非幂等**：每次调用创建新问卷
6. **≤6 题建议不要分页**：分页符 `=== 分页 ===` 在小问卷中不必要
