# 填报规则库（AI 速查）

> 来源：志愿填报基础知识 + 各地模式详解 + 系统思路(2024+2025) + SOP稳保策略
> 用途：咨询中答疑——投档/滑档/调剂/选科/赋分/省规则差异

---

## 一、录取流程核心概念

### 1.1 投档与提档

| 概念 | 定义 | 关键主体 |
|:--|:--|:--|
| **投档** | 省考试院按规则把你的档案投给大学 | 省考试院 |
| **提档** | 大学从考试院"提走"你的档案开始审核 | 大学招生办 |
| **投档线** | 省考试院划定的该批次最低投档分数线 | 省考试院 |
| **录取线** | 大学在每个省实际录取的最低分 | 大学 |

顺序：考试院投档 → 大学提档 → 大学审核 → 录取/退档

### 1.2 退档

大学提档后审核发现不符合条件，把档案退回省考试院。

**常见退档原因**：
- 总分偏低（排在提档人数末尾）
- 不服从专业调剂（所有填的专业都满了）
- 体检不合格（色盲报临床医学等）
- 单科成绩不达标（外语类专业英语分不够）
- 选科不符合专业要求

> 退档后本批次不再投档，只能等征集志愿或下一批次。平行志愿模式下退档=本批次作废。

### 1.3 滑档

所有填报的志愿都未达到投档线，档案未被任何学校提取。

**滑档原因**：填报的所有院校专业组投档线都高于考生分数。

> 滑档后同样等征集志愿或下一批次。稳保策略的核心目标就是防止滑档。

### 1.4 调剂

当考生被提档，但所填专业均已录满时，如勾选「服从调剂」则被分配到同专业组内有空缺的专业。

| 服从调剂 | 不服从调剂 |
|:--|:--|
| 被调剂到组内其他专业 | 直接退档 |
| 至少保证被该校录取 | 本批次作废 |

> 新高考「院校+专业组」模式下，调剂只在组内进行，不会跨组调剂。所以填报时要关注组内所有专业是否能接受。

## 二、专业分配规则

大学提档后，内部如何将考生分配到具体专业：

### 2.1 分数清（分数优先）

按分数从高到低排队，依次满足每个人的专业志愿。分数高的人先挑。

**特点**：高分考生优势最大，第一志愿不浪费。

### 2.2 专业清（专业优先）

先在每个专业的第一志愿考生中按分数排序录取，不满再看第二志愿。

**特点**：第一志愿选择极为关键。第一志愿没录到，即使分数高也可能被调剂。

### 2.3 专业级差

每个志愿之间设减分台阶（如3-2-1分）。未录取则扣除级差分后参与下一志愿竞争。

| 规则 | 高分友好度 | 风险点 |
|:--|:--|:--|
| 分数清 | ⭐⭐⭐⭐⭐ | 低分专业志愿需慎重排序 |
| 专业清 | ⭐⭐ | 第一志愿选错=全盘输 |
| 专业级差 | ⭐⭐⭐ | 级差分数要算清楚 |

> 大部分 985/211 采用分数清，省属院校部分采用专业清。须查看目标院校《招生章程》。

## 三、新高考选科与赋分

### 3.1 两种选科模式

| 模式 | 省份 | 选科方式 |
|:--|:--|:--|
| 3+3 | 浙江、上海、北京、天津、山东、海南 | 语数外 + 6选3 |
| 3+1+2 | 其余新高考省份 | 语数外 + 物理/历史2选1 + 化生政地4选2 |

### 3.2 赋分制

选考科目不按原始分，按排名等级赋分。

| 赋分方法 | 省份 | 逻辑 |
|:--|:--|:--|
| 等级内固定分 | 浙江、上海等 | 按排名百分比，每等级固定分数 |
| 等级内区间转换 | 3+1+2省份 | 同等级内按原始分排名线性转换 |

> 赋分后分数不一定等于原始分。考生应关注「位次」而非绝对分数。

### 3.3 选科对专业的影响

- 「理工农医」92%+专业要求**物理+化学**双选
- 临床医学/口腔医学「物理+化学」必选比例达 100%
- 法学、经济类多数不限选科，但金融科技/精算等新方向要求物理
- 选科不符合 → 无法投档该专业

## 五、分批录取的重要策略概念

### 5.1 提前批

在普通批之前录取，通常包含：军校、公安院校、公费师范生、定向医学生、飞行员、航海类、综合评价录取、三大专项计划等。

**关键规则**：
- 提前批录取后，不再参加后续批次
- 提前批未被录取，不影响普通批
- 只有符合条件（体检、政审、面试等）的考生才能填报

### 5.2 征集志愿

每批次录取结束后，省考试院公布未招满的院校+专业名单，允许未被录取的考生重新填报。

> 征集志愿是滑档/退档考生的补救通道，但好专业通常在第一轮就招满了。

### 5.3 平行志愿 vs 顺序志愿

| | 平行志愿 | 顺序志愿 |
|:--|:--|:--|
| 投档规则 | 分数优先，遵循志愿 | 志愿优先，后看分数 |
| 第一志愿重要性 | 重要但非致命 | **决定性的** |
| 最怕的情况 | 滑档（全不过线） | 第一志愿没录到 |

> 当前大部分批次的常规录取采用平行志愿，但部分特殊类型招生（如艺术类校考）仍用顺序志愿。

## 六、稳保策略

### 6.1 定义

稳保策略 = 以**需求匹配**为核心，只填报符合考生需求且录取确定性高的院校专业组，杜绝「冲一冲好学校的差专业」。

### 6.2 三层结构

1. **最想上的学校** → 符需求的专业 → 按想上程度排序
2. **比较想上的学校** → 符需求的专业 → 按想上程度排序
3. **一般想上的学校** → 符需求的专业 → 按想上程度排序

> "需求"包括：无调剂到差专业风险 + 专业/城市/院校符合个人偏好。

### 6.3 与「冲稳保」对比

| | 稳保策略 | 冲稳保 |
|:--|:--|:--|
| 核心目标 | 需求匹配，杜绝差专业 | 分数最大化利用 |
| 冲的学校 | 不冲 | 填报20%分数更高的学校 |
| 最大风险 | 错过好学校的冷门机会 | 进入好学校的差专业 |
| 推荐场景 | 专业导向型考生 | 院校层次极度敏感的考生 |

### 6.4 操作步骤

1. 列出符合需求的全部院校专业组
2. 剔除有明显调剂到不接受专业的组
3. 去掉对目标专业录取希望极低的组
4. 按想上程度从高到低排列
5. 填满所有志愿栏（越多越稳）

## 七、位次转换与分数线使用

### 7.1 位次是核心

高考录取看**位次**而非分数。每年试卷难度不同，同一分数对应的位次不同。一分一段表公布后，用位次去匹配往年的录取位次，而非用分数去匹配往年分数。

### 7.2 高分段选手（985段）

出分后，查看前3年和你相同位次的考生都去了哪些学校和专业。

### 7.3 特控线/本科线附近选手

查看前3年和分数线有类似相对位置（±20分）的考生去向，因为分数线附近位次波动大。

### 7.4 通用位次转换法

```
我的位次 / 今年分数线对应位次 = 参考位次X / 去年分数线对应位次
```

## 八、常见填报陷阱

| 陷阱 | 说明 |
|:--|:--|
| **大类招生** | 入学时不分专业，大二根据绩点分流——热门方向竞争极激烈。不是「进大类=任选专业」 |
| **专业组打包** | 热门专业和冷门专业打包在同一组——服从调剂可能被调到组内冷门专业 |
| **转专业承诺** | 部分学校宣传「进校后可转专业」——实际转出率极低（有的不到5%）。不要买"先进去再转"的彩票 |
| **新增专业** | 连续三年大量新增的专业（如人工智能全国530+所开设）需谨慎——师资和培养方案可能不成熟 |
| **停招信号** | 连续三年被撤销的专业（如公共事业管理）慎重填报——就业市场已经给出答案 |
| **民办/独立学院前缀** | XX大学XX学院多数是独立学院（民办），分数线远低于本部 |
| **只盯分数不盯位次** | 每年试卷难度不同，只看分数不看位次会严重误判 |

## 九、咨询中回答志愿规则的边界

**AI 可以回答的**：
- 提档/退档/调剂机制的定义和案例
- 三种志愿模式的差异
- 新高考选科与专业匹配规则
- 稳保策略的方法论

**AI 不得替咨询侠决定的**：
- 具体某考生该报哪个学校
- 冲稳保的具体比例分配
- 某个学校的录取概率
- 各省当年政策的具体细节（应建议查省教育考试院官网）

**必须让考生自行核实的信息**：
- 目标院校的《招生章程》（特别是专业分配规则）
- 目标专业的具体选科要求
- 当年的体检限制
- 本省当年的志愿填报截止时间
