## 🚀 新人引导：5 分钟上手

第一次用咨询侠 Skill？

### 只需知道三件事

**1. 你在对话里说指令，AI 输出内容，你负责发到微信群里**
不需要学任何技术。对话就是操作界面。

**2. 一次完整咨询的最小指令链**

```
【启动】
后续启动 → 创建排期表 → 批量导入考生 → 自动生成题包+问卷

【咨询前】
考生已作答 + 答案          ← 回收答案
生成专业推荐               ← AI 生成 3-5 个专业推荐文档
导出docx / 创建在线推荐    ← 导出文档给考生

【咨询中】
开始咨询 文字              ← 进入话术引导模式
开场白 → 排除排序 → 五维度 → 通用总结 → 结束咨询

【咨询后】
开始复盘 → 输出复盘 → 导出复盘
```

**3. 遇到不懂的，说 `话术指导`**
任何时候说「话术指导」都会显示当前阶段可用的话术指令。

### Skill 能做什么、不能做什么

| ✅ AI 全自动 | 🔶 AI 生成+人工把关 | ❌ 必须人工 |
|:-----|:-----|:-----|
| 分析考生信息、生成题目包 | 五维度话术（自动代入考生画像） | 拉群加好友 |
| 生成专业/城市推荐文档 | AI 复盘初稿（需结合你的感受） | 处理家庭代咨询 |
| 导出 DOCX、创建在线文档 | 答疑话术（可微调语气） | 控场/情绪安抚 |

## 第一阶段：咨询前 — AI 分析

> ⏱️ 不计入 40 分钟正式咨询 | 🤖 AI 主导、人工确认

### 步骤 1：创建考生档案

```
@咨询侠:切换:考生昵称
```

系统自动在 `cases/考生昵称/` 下创建档案文件。之后粘贴考生信息收集表。

### 步骤 2：生成信息确认题目包（Prompt0）

```
生成题目包
```

AI 读取 `./知识库/核心方法论/AI提示词模板.md` 中的 Prompt0，对 5 个范围逐一判断把握度（分数利用/家庭关系/经济关系/自我评估/金钱观念）。达 95% 把握的范围跳过，不足的范围生成选择题。

**输出**：一次性题目包，≤15 题，每道题含题型标注 + 选项 + 咨询侠参考。复制发给学生即可。

> 💡 **导出腾讯问卷**：生成题目包后，输入 `导出腾讯问卷` 可一键创建为腾讯问卷在线链接，学生手机上直接作答，后台自动回收答案。

### 步骤 3：收集作答，生成专业推荐（Prompt1）

学生答完后，粘贴答案：
```
考生已作答
1. A
2. B
...
```

然后：
```
生成专业推荐
```

AI 组装原始信息+题目原题原答，判断把握。未达则逐题追问（一次一题）；达则输出完整推荐文档，含 3-5 个专业，每个有推荐原因/适合点/发展方向/赚钱路径类型/学校层次敏感度/注意事项 + 对比表 + 避坑清单。

> 💡 **增强检索**：生成推荐时，AI 检索 `数据层/专业决策库.md` 获取专业培养/就业/薪资/院校敏感度数据，检索 `数据层/行业薪资与工具箱.md` 获取薪资路径和工具教学，而非仅凭通用知识推断。

### 步骤 4：导出文档

```
导出docx               ← 本地 Word 文件
创建在线推荐           ← 腾讯文档在线链接（可分享给考生）
```

两步都先生成 `.md` 源文件保存到 `cases/考生/`，再从 `.md` 导出。

### 步骤 5：城市推荐（选用）

```
生成城市推荐
```

AI 基于 Prompt2 + `数据层/城市产业库.md`（产业集群+专业-城市匹配）+ `数据层/行业薪资与工具箱.md` 生成。

## 第二阶段：咨询中 — 结构化话术引导

> ⏱️ 40 分钟 | 🔶 AI 提供话术，人工控场

### 进入方式

```
开始咨询             ← 确认咨询形式后进入
话术指导             ← 任何时候查看可用指令
```

### 完整框架和指令速查

**咨询前建联话术**（在正式咨询前用）：

| 指令 | 用途 |
|------|------|
| 私聊 | 添加微信私聊，自我介绍 + 流程链接 + 确认时间。考生提问时控场 |
| 拉群·介绍规则 | 建群后发三板块介绍+40分钟+改期超时规则 |
| 拉群·确认时间 | 文字咨询，时间定在考生确认的时间 |
| 拉群·信息确认 | 调取考生档案四板块（基本信息/关键约束/优先级排序/咨询诉求）+ 题包问卷链接 |
| `咨询前提醒` | 正式咨询前5分钟提醒+发专业推荐文档 |

**咨询中逐环节话术**：

| 框架位置 | 指令 | AI 自动做的事 |
|------|------|------|
| 0. 开场白 | `开场白` | 自动匹配语音/文字版本 |
| (1) 排除排序 | `排除排序` | 引用推荐文档的专业列表 |
| (2) 框架引入 | `框架引入` | 五维度名称+方法迁移预告 |
| (3) 培养计划 | `讲培养计划` | 检索知识库专业课程数据+结合考生科目分析。定义概念部分使用培训版标准定义原文。 |
| (4) 学校要求 | `讲学校要求` | 检索院校评估框架+结合分数段分析。定义概念部分使用培训版标准定义原文。 |
| (5) 深造要求 | `讲深造要求` | 结合考生读研意愿分析。定义概念部分使用培训版标准定义原文。 |
| (6) 硬性要求 | `讲硬性要求` | 确认选科+身体限制。定义概念部分使用培训版标准定义原文。 |
| (7) 赚钱能力 | `讲赚钱能力` | 检索行业薪资数据+结合经济约束。定义概念部分使用培训版标准定义原文。 |
| (8) 整体确认 | `整体确认` | 五维度总结清单 |
| 板块二 | `讲城市` | 检索城市产业数据 |
| 板块三 | `讲院校` | 检索院校评估框架 |
| 答疑 | `答疑：常规/不熟悉/纠结/焦虑/好问题/收尾/家里意见不一致` | 按场景输出策略 |
| 收尾 | `通用总结` + `结束咨询` | 固定话术模板（不引用具体内容）→ @运营官 |
| 收尾（按需） | `总结` | 专业优先→院校→城市 + 授人以渔（仅当话术被完整遵循时使用） |

**每个维度话术自动**：①代入考生画像（分数/专业名/MBTI/关键约束）②根据考生类型微调（焦虑型多安抚、话少型用锚定性问题、纠结型给对比表）

> 💡 **知识库检索**：培养计划维度检索 `数据层/专业决策库.md`；学校要求维度检索 `数据层/院校评估库.md`；赚钱维度检索 `数据层/行业薪资与工具箱.md` + `数据层/专业决策库.md`；城市维度检索 `数据层/城市产业库.md`；院校维度检索 `数据层/院校评估库.md`；答疑时检索 `数据层/填报规则库.md`。

### 考生类型适配策略

| 考生类型 | 调整方法 |
|------|------|
| **目标极度清晰型** | 咨询基调 = "验证"而非"推荐"。排除排序可加速。重点在院校梯度+职业路径分叉 |
| **方向模糊型** | 题目包是关键——用逼选题让考生自己确认偏好的方向 |
| **方向完全偏移型** | Prompt0 第1题直捅矛盾——"你填工学是因为喜欢还是好就业？" 让考生自己确认转向 |
| **话少/INTJ/INFP 型** | 每个维度结束不用「有没有问题」，改用锚定性问题：「刚才三个方向，你现在直觉更倾向哪个？」 |
| **无画面感型** | 每个维度至少嵌入一个具象场景。不说"你要学解剖学"，说"大二你在康复科看着带教老师帮病人坐起来" |

### 答疑场景速查

| 场景 | 指令 | 核心策略 |
|------|------|------|
| 有把握的问题 | `答疑：常规` | 简明扼要+数据支撑+决定权还给学生 |
| 超出知识范围 | `答疑：不熟悉` | 坦诚告知+推荐渠道+提醒交叉验证 |
| 两个选项纠结 | `答疑：纠结` | 列优缺点+逼选取舍+选更适合自己的 |
| 压力大/恐惧 | `答疑：焦虑` | 共情+降低灾难化+一步一步来 |
| 深度提问 | `答疑：好问题` | 先肯定+回答+鼓励深入思考 |
| 家长vs考生 | `答疑：家里意见不一致` | 不直接对抗+用五维度数据说服 |

## 第三阶段：咨询后 — 闭环

### 收尾

收尾分两步：先通用总结（必须），再定制总结（按需）。

```
通用总结          ← AI 输出固定收尾话术（不引用具体内容，安全通用）
结束咨询          ← @运营官 本场咨询已完成。
总结（按需）      ← 仅当话术完整遵循时，输出专业优先→院校→城市结构化总结
```

群内发：`@运营官 本场咨询已完成。`

### AI 复盘

```
开始复盘          ← 粘贴聊天记录/截图目录
输出复盘          ← AI 生成四步复盘（引导提问+专业补充）
导出复盘          ← 生成 DOCX
创建在线复盘      ← 创建腾讯文档在线链接
```

复盘四步结构：①考生根本矛盾 ②手段-目的链条表 ③亮点+不足矩阵 ④下次优化建议

## 🧠 知识库检索指南

咨询侠拥有完整知识库（`./知识库/`），v2.2 已完成 AI 蒸馏重构——18 份源文档 → 5 份速查库 + 1 份参考数据 + 1 份 SOP：

### 三层结构

| 层级 | 目录 | 内容 |
|------|------|------|
| **核心方法论** | `核心方法论/`（8份） | Prompt0/1/2、话术指南、培训思路、复盘流程、信息收集清单、去AI化规则 |
| **数据层** | `数据层/`（5份） | 5 份 AI 蒸馏速查库 |

### 数据层速查库与检索时机

| 速查库 | 检索时机 |
|------|------|
| `填报规则库.md` | 答疑（投档/退档/滑档/调剂/选科/赋分/各省模式/稳保策略）、定制总结环节（按需） |
| `专业决策库.md` | Prompt1 生成（专业培养/就业/薪资/深造/选科/院校敏感度/误区辨析）、讲培养计划 |
| `院校评估库.md` | 讲学校要求（985/211/双一流名单/7维评估/部委直属/推免率）、讲院校 |
| `城市产业库.md` | Prompt2 生成、讲城市（5层格局/31省产业集群/专业-城市匹配/SOP框架） |
| `行业薪资与工具箱.md` | 讲赚钱能力（薪资路径/6因素框架/就业四象限）、推荐工具给考生 |

### 检索原则

- 生成专业推荐时优先检索 `数据层/专业决策库.md` 中对应专业卡片（培养/就业/薪资/院校敏感度），而非仅靠通用知识
- 考生提问填报规则时，必须检索 `数据层/填报规则库.md`——各省规则差异大，不可凭通用知识作答
- 讲解查询方法时引用 `数据层/行业薪资与工具箱.md` 中的工具速查表（阳光高考/夸克/BOSS直聘），而非泛泛说"你去查"
- 评估院校层次时检索 `数据层/院校评估库.md`，注意行业强校 > 综合排名的逻辑
