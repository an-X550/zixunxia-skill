# 行业薪资与工具箱（AI 速查）

> 来源：行业部分 + 工具资料 + 信息渠道
> 用途：咨询中「讲赚钱能力」维度、答疑推荐工具、考生3小时了解专业方法论

---

## 一、薪资查询路径

### 1.1 权威数据源

| 来源 | 内容 | 查询方式 |
|:--|:--|:--|
| **国家统计局** | 行业平均薪资（年度发布） | 搜索「国家统计局+行业工资」 |
| **BOSS直聘/智联招聘** | 具体岗位薪资区间 | 搜索目标城市+岗位名称，看「薪资范围」 |
| **夸克高考** | 专业应届到毕业十年薪资、就业方向、地区分布 | 夸克→夸克高考→查专业→点薪资 |
| **麦可思就业报告** | 本科生就业/薪资/满意度（年度发布） | 搜索「麦可思 中国本科生就业报告」或「XX大学 就业质量报告」 |

### 1.2 薪资数据使用注意事项
- **看中位数**而非平均数——平均数被极端值拉高
- **优先看本校数据**——同专业不同学校薪资差距可达数倍
- **区分税前/税后**——大部分平台显示的为税前薪资
- **区分是否有五险一金**——国企薪资结构中公积金占比不小

## 二、6因素就业分析框架

咨询中评估某专业+城市对考生的适配度：

| 因素 | 说明 |
|:--|:--|
| **1. 城市资源** | 该城市是否有该专业的产业集群和头部企业 |
| **2. 学校资源** | 该校是目标企业的目标院校/校招覆盖 |
| **3. 学历层次** | 目标岗位的最低学历要求（本/硕/博） |
| **4. 家庭连接** | 家庭在目标行业内的人脉和资源 |
| **5. 专业壁垒** | 该专业的技术壁垒和证书门槛（如医师/CPA/法律） |
| **6. 个人能力** | 作品集/项目经验/竞赛成绩等可脱离院校品牌的个人能力 |

> 前4项为结构性因素，后2项为个人能动性因素。院校依赖程度越低的专业，后2项权重越大。

## 三、就业四象限

| | 通用能力主导 | 专业壁垒主导 |
|:--|:--|:--|
| **体制内/公共部门** | 公务员(行测+申论)、教师编 | 医师、法官/检察官、会计师(CPA) |
| **体制外/私营部门** | 新媒体/运营/互联网产品 | 律师、软件工程师、芯片设计、量化金融 |

> 专业壁垒主导+体制内 = 最稳定的就业路径（但院校依赖通常最高）。通用能力主导+体制外 = 最灵活的就业路径。

## 四、工具速查表

### 4.1 推荐给考生的工具

| 用途 | 工具 | 操作 |
|:--|:--|:--|
| **查官方专业定义** | 阳光高考网(gaokao.chsi.com.cn) | 搜索专业名→记录专业代码/授予学位/一句话定义 |
| **查专业开设课程** | 夸克高考→查专业→XX专业→开设课程（简版） | 截屏核心课程前5门，标红数学/编程/实验类 |
| **查培养方案（全版）** | 头部大学对应学院/系官网 | 搜「XX大学+XX专业+本科培养方案」 |
| **查就业数据** | XX大学信息公开网→毕业生就业质量报告 | 看就业率（注意灵活就业占比）/典型岗位/薪酬中位数 |
| **查学科排名** | [青塔](https://www.cingta.com/) | 查教育部学科评估等级（A+到C-） |
| **查往年招生数据** | 夸克高考→查大学→招生计划/专业分数线 | 看近3年在当地招生人数/位次/学费 |
| **查院校信息** | 夸克高考→性格测试/查大学 | 双一流/国家特色/硕博点/学科评级 |
| **模拟志愿填报** | 夸克高考→模拟填报 | 输入信息后按稳保策略填充 |
| **MBTI测试** | 夸克高考→性格测试→MBTI | 辅助参考，信效度有限 |
| **霍兰德测试** | [xmcs.cn/x/hld60](https://www.xmcs.cn/x/hld60) | 6种职业兴趣类型 |
| **天赋智能测试** | [xinlixue.cn](https://www.xinlixue.cn/wp/archives/2269.html) | 8种天赋维度 |
| **查城市生活** | colleges.chat、贝壳找房、高德通勤报告 | 宿舍/租房/通勤 |
| **查企业社保规模** | 企查查/天眼查 | 输入「专业关键词+城市」→看参保人数 |

## 五、考生推荐操作流程

### 5.1 3小时快速了解一个专业

```
阳光高考查定义（30min）→ 大学官网看课程（→）→ 就业报告找去向（30min）→ BOSS直聘看薪资要求（30min）→ 三问评估适配（60min）→ 对比表防混淆（30min）
```

**三问评估法**：
1. 是否愿意每天接触该专业核心课程内容？
2. 能否接受该专业典型岗位的工作场景？
3. 是否具备或愿意发展专业要求的核心能力？

> 两项以上为「是」→ 可考虑。只有一项或零项 → 重新考虑。

## 六、行业趋势判断框架

### 6.1 三看原则

| 维度 | 看什么 | 信号 |
|:--|:--|:--|
| **看政策** | 十五五规划、「双碳」战略、新质生产力 | 政策支持=增量进入 |
| **看技术** | AI替代/创造、产业智能化 | AI创造：大模型训练师、AI伦理研究员。AI替代：基础翻译、基础记账 |
| **看周期** | 行业处于上升/平台/下降期 | 上升=机会多、下降=慎入（即使名字好听） |

### 6.2 当下趋势信号

- **上升方向**：AI/大模型、低空经济、新能源/储能、生物制造、半导体、银发经济、数字文旅
- **平台/调整期**：互联网消费端、传统汽车制造、房地产/建筑
- **结构性萎缩**：基础翻译、传统媒体、银行柜员、基础会计

## 七、夸克APP操作流程

夸克浏览器→首页「夸克高考」→输入考生信息（省份+选科+分数/位次）：

| 功能 | 路径 |
|:--|:--|
| 查大学 | 夸克高考→查大学→搜索校名→看开设专业/双一流/硕博点 |
| 查专业 | 夸克高考→查专业→看课程/就业前景/薪资/男女比例 |
| 查往年分数 | 夸克高考→查大学→XX大学→专业分数线（按省份+年份） |
| 模拟填报 | 夸克高考→模拟填报→按稳保策略填满 |
| MBTI测试 | 夸克高考→性格测试→MBTI职业性格测评 |

> **稳保策略操作**：在夸克里挑选自己想上且能稳上的专业+院校组合，去掉有明显调剂风险的组，按想上程度排序→完成。

## 九、咨询侠答疑工具箱速查

| 考生问题类型 | 推荐工具/渠道 | 话术要点 |
|:--|:--|:--|
| 这个专业学什么 | 夸克→开设课程；头部院校学院官网→培养方案 | 「你可以去XX大学XX学院官网看他们的培养方案，课程表一目了然」 |
| 这个专业赚多少钱 | 夸克→就业前景；BOSS直聘→搜岗位 | 「你可以在BOSS直聘上搜这个专业名+城市，看招聘信息里写的薪资范围」 |
| 这个学校好不好 | 夸克→查大学；青塔→学科评估 | 「你去夸克看这个学校的双一流/国家特色/硕士博士点」 |
| 这个专业能不能考医师/教师证 | 阳光高考→查专业→看授予学位 | 「授予医学学士+临床医学类→可考。医学技术类→不可考」 |
| 怎么填志愿 | 夸克→模拟填报 | 「稳保策略：挑想上且能稳上的专业组，按想上程度排序填满」 |
| MBTI/职业倾向 | 夸克→性格测试 | 「可以参考但不能全信，最好找在读大学生聊聊真实的专业体验」 |
