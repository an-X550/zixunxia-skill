# 咨询侠 — 高考志愿咨询 AI 副驾驶

> 作者：杰 | 基于问问大象「撑伞侠」工作流体系构建

## 安装

### 1. 复制 Skill

将整个 `.claude/skills/咨询侠/` 目录复制到目标电脑的 `.claude/skills/` 下。

### 2. 安装依赖

| 依赖 | 用途 | 安装命令 |
|------|------|---------|
| Python 3 | DOCX 导出脚本 | 系统已有或 [python.org](https://python.org) |
| python-docx | Word 文档生成 | `pip install python-docx` |
| Node.js | MCP CLI 运行环境 | [nodejs.org](https://nodejs.org) LTS 版 |
| mcporter | MCP 命令行工具 | `npm install -g mcporter` |

### 3. 配置腾讯文档（可选，在线文档功能）

```powershell
# 1. 浏览器获取 Token：https://docs.qq.com/scenario/open-claw.html
# 2. 注册 MCP 服务
mcporter config add tencent-docs "https://docs.qq.com/openapi/mcp" --header "Authorization=<Token>" --transport http --scope home
# 3. 验证
mcporter list tencent-docs
```

### 4. 配置腾讯问卷（可选，在线问卷功能）

```powershell
# 方式一：环境变量
$env:TENCENT_SURVEY_TOKEN = "wjpt_xxx..."
# Token 以 wjpt_ 开头，约 70 字符。在 https://wj.qq.com/claw 创建

# 方式二：mcporter 手动配置
mcporter config add tencent-survey "https://wj.qq.com/api/v2/mcp" --header "Authorization=Bearer <Token>" --transport http --scope home

# 验证
mcporter list tencent-survey
```

## 快速开始

```
【启动】
后续启动 → 创建排期表 → 批量导入考生 → 自动生成题包+问卷

【咨询前】
考生已作答 + 答案          ← 回收答案
生成专业推荐               ← AI 生成 3-5 个专业推荐文档
导出docx / 创建在线推荐    ← 导出 Word / 腾讯文档链接

【咨询中】
开始咨询 文字              ← 进入话术引导模式
开场白 → 排除排序 → 五维度 → 通用总结 → 结束咨询

【咨询后】
开始复盘 → 输出复盘 → 导出复盘
```

## 三大模块

### 咨询前 — AI 分析 + 建联话术

**分析指令**

| 指令 | 作用 |
|------|------|
| `@咨询侠:切换:昵称` | 创建/切换考生档案 |
| `开始咨询前准备` | 粘贴信息收集表 |
| `生成题目包` | Prompt0：生成 ≤15 题确认选择题包 |
| `导出腾讯问卷` | 一键创建在线问卷 + 配套话术 |
| `考生已作答` + 答案 | 回收答案写入档案 |
| `生成专业推荐` | Prompt1：生成 3-5 个专业推荐文档 |
| `生成城市推荐` | Prompt2（选用）：生成城市推荐文档 |
| `导出docx` / `创建在线推荐` | 导出 Word / 腾讯文档链接 |

**建联话术**（正式咨询前发给考生）

建联分两个阶段，由 AI 在启动流程中自动引导：

| 阶段 | 内容 |
|------|------|
| 私聊 | 自我介绍 + 流程链接 + 确认咨询时间。考生提问时控场，引导至正式咨询 |
| 拉群·介绍规则 | 三板块介绍 + 40分钟 + 改期/超时规则 + 三人小群 |
| 拉群·确认时间 | 文字咨询，时间定在考生确认的时间 |
| 拉群·信息确认 | 调取考生档案输出四板块（基本信息/关键约束/优先级排序/咨询诉求）+ 题包问卷链接 |
| 咨询前提醒 | 正式咨询前 5 分钟提醒 + 发送专业推荐文档 |

### 咨询中 — 话术引导（40分钟）

**板块一：专业五维度**

| 指令 | 内容 |
|------|------|
| `开场白` | 时长/板块/可随时打断 |
| `排除排序` | 浏览推荐→划掉不感兴趣→排序 |
| `框架引入` | 五个维度名称 + 方法迁移预告 |
| `讲培养计划` | 大学四年学什么 + 结合考生科目 |
| `讲学校要求` | 院校层次依赖度 + 结合分数段 |
| `讲深造要求` | 是否需要读研 + 结合读研意愿 |
| `讲硬性要求` | 选科限制 + 身体要求确认 |
| `讲赚钱能力` | 就业去向 + 薪资 + 结合经济约束 |
| `整体确认` | 五维度总结清单 |

**板块二/三 + 答疑**

| 指令 | 内容 |
|------|------|
| `讲城市` | 企业资源/交通/生活三维度 |
| `讲院校` | 专业设置/招生数据/强势专业/升学/就业竞争力 |
| `答疑：常规/不熟悉/纠结/焦虑/好问题/收尾/家里意见不一致` | 七种场景策略 |

**收尾**

| 指令 | 内容 |
|------|------|
| `总结` | 专业优先→院校→城市 + 授人以渔 |
| `结束咨询` | 感谢+祝福+后续资源渠道 |

### 咨询后 — AI 复盘

| 指令 | 作用 |
|------|------|
| `开始复盘` | 粘贴聊天记录/截图 |
| `输出复盘` | 四步结构（根本矛盾→手段目的→亮点不足→优化建议） |
| `导出复盘` / `创建在线复盘` | 导出 DOCX / 腾讯文档 |

## 话术个性化

Skill 自动代入考生画像并根据类型微调：

| 考生类型 | 调整 |
|---------|------|
| 焦虑型 | 多安抚 + 降低灾难化 |
| 话少型 | 锚定性问题逼反馈 |
| 纠结型 | 对比表格 + 逼选取舍 |
| 经济高压型 | 展开薪资路径 + 具体数字 |
| 低分段 | 强调行业不看学历的方向 |
| 家庭意见不一致 | 用五维度数据说服 |

用户可随时干预：「换个语气」「太啰嗦了精简」。

## 自然语言推断

| 你说了什么 | Skill 推断为 | 自动执行 |
|-----------|-------------|---------|
| 「帮这个考生分析一下」 | 咨询前-专业推荐 | 检查信息是否足够 |
| 「开始跟考生聊了」 | 咨询中 | 切换模式，输出指令菜单 |
| 「帮我看看这次咨询哪里有问题」 | 咨询后-复盘 | 引导粘贴材料 |
| 「接下来讲XX维度」 | 咨询中-指定环节 | 输出该环节话术 |
| 「考生好像很紧张」 | 咨询中-答疑 | 输出安抚/纠结类话术 |
| 「该结束了」 | 咨询中-收尾 | 输出总结+收尾话术 |
