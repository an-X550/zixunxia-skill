## 二、工学门类热门专业卡片

### 2.1 计算机类

#### 软件工程
| 字段 | 内容 |
|:--|:--|
| **培养计划** | Java全栈/DevOps/AI驱动开发。核心课：数据结构、软件测试、生成式AI应用。全国530+所高校开设 |
| **就业前景** | 互联网大厂开发岗应届15-25万/年。AI算法岗28.5万/年起。传统Java后端月薪7k-10k，基础开发岗需求近两年降32% |
| **深造需求** | 本科可就业基础开发/测试岗。AI算法/系统架构岗要求硕士+ |
| **报考条件** | 物理+化学必选（绝大多数公办高校）。数学+逻辑能力突出 |
| **院校依赖** | **7分**。腾讯校招严选33所，字节19所。双非生面临保研通道狭窄+岗位被AI替代的双重压力 |
| **典型方向** | 清华：智能软件工程；浙大：AI驱动+金融科技；北邮/西电/深大：均入腾讯字节严选名单；杭电/重邮：IT产业聚集区应用型强校 |

#### 人工智能
| 字段 | 内容 |
|:--|:--|
| **培养计划** | 深度学习/NLP/计算机视觉。新增通识→专业→跨学科三级课程体系。全国530+所高校开设 |
| **就业前景** | 平均起薪56.2万/年（含股权绩效，幂律分布极严重）。AI科学家月薪13.7万。头部岗位高度集中于19-33所严选院校硕博 |
| **深造需求** | **90%顶尖企业要求硕士+**。纯本科学历就业竞争力快速下降 |
| **报考条件** | 物理+化学组合。数学+编程能力极突出 |
| **院校依赖** | **9分**。头部企业核心算法岗严选19-33所院校。双非生进入大厂AI核心岗极为困难。薪资均值被极高端岗位拉高 |
| **典型方向** | 清华：大模型架构；北大：多模态学习；上交：AI安全+科学智能；浙大：AI+多学科交叉；北邮：AI+通信；西电：AI+信息安全 |

#### 数字媒体技术
| 字段 | 内容 |
|:--|:--|
| **培养计划** | 编程+美术+AI工具三位一体。Unity/Unreal引擎开发，AIGC生成技术，虚拟制片。全国286个专业点 |
| **就业前景** | 覆盖游戏/影视/VR/数字营销。本科起薪10-20万/年。作品集比学历更重要 |
| **深造需求** | 技术美术岗需硕士。创意设计/前端开发岗本科可胜任 |
| **报考条件** | 物理+化学组合（多数公办高校）。部分高校要求作品集 |
| **院校依赖** | **7分**。作品集可在一定范围内弥补院校。但大厂设计岗有院校筛选。普通院校在工具链实训上资源不足 |
| **典型方向** | 浙大：计算机图形学；中传：虚拟制片；哈工大(威海)：VR交互；北邮：智能媒体融合 |

## 八、Prompt1 检索提示

生成专业推荐时按以下优先级检索本库：

1. **先查门类通性**——用「12学科门类速查」判断大方向匹配度
2. **再查具体专业卡片**——每个专业含培养/就业/深造/选科/院校依赖
3. **交叉验证误区表**——推荐专业名是否容易让考生误解
4. **关注新增专业**——2025新增专业有政策红利但需确认报考条件

**院校依赖分数使用说明**：
- 9-10分：必须在推荐文档中强调院校层次对就业的决定性影响
- 7-8分：提醒考生院校有影响但个人能力可补足
- 5-6分：院校影响较小，可推荐更多层次学校选择
